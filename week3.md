| **Day 11** | **14/07/2026** | <ul><li><b>Supervised Learning</b> – Learned how models use labeled data to learn relationships between input features and target outputs for making predictions.</li><li><b>Supervised Learning Workflow</b> – Understood the complete process of data preparation, train-test split, model training, evaluation, and prediction.</li><li><b>Classification vs Regression</b> – Learned that classification predicts discrete categories while regression predicts continuous numerical values.</li><li><b>Classification Algorithms</b> – Introduced Logistic Regression, Naive Bayes, KNN, SVM, Decision Tree, and Random Forest.</li><li><b>Regression Algorithms</b> – Introduced Linear Regression, Ridge Regression, and Lasso Regression.</li><li><b>Practical Application</b> – Applied Logistic Regression to student placement and teen mental health datasets, demonstrating how the same supervised learning workflow can be used across different domains.</li><li><b>Model Generalization</b> – Learned that predictions depend on the combination of multiple features rather than a single variable.</li></ul> |
| **Day 12** | **15/07/2026** | <ul><li><b>Naive Bayes</b> – Learned a probabilistic classification algorithm based on Bayes' Theorem and its assumption of feature independence.</li><li><b>K-Nearest Neighbors (KNN)</b> – Learned how new observations are classified based on the majority class among their nearest neighboring points.</li><li><b>Support Vector Machine (SVM)</b> – Understood how SVM finds an optimal boundary with maximum margin to separate classes.</li><li><b>Linear & Non-Linear Classification</b> – Learned how SVM can use straight or curved decision boundaries depending on the data.</li><li><b>Algorithm Comparison</b> – Compared Naive Bayes, KNN, and SVM on the same Teen Mental Health dataset.</li><li><b>Performance Analysis</b> – Naive Bayes achieved about 99.17% accuracy, while KNN and SVM achieved about 98.33% each.</li><li><b>Algorithm Selection</b> – Learned that the best algorithm depends on the dataset, feature relationships, problem type, and application domain.</li></ul>                                                                                                                 |

| **Day 14** | **17/07/2026** | <ul><li><b>Decision Tree</b> – Learned how classification decisions are made using a sequence of if-then-else splits arranged in a tree structure.</li><li><b>Gini Impurity & Entropy</b> – Understood how impurity measures are used to identify the best feature for splitting data.</li><li><b>Information Gain</b> – Learned how Decision Trees select splits that provide the most useful separation between classes.</li><li><b>Overfitting</b> – Observed that the Decision Tree achieved 100% accuracy, highlighting how perfect performance can indicate overfitting.</li><li><b>Random Forest</b> – Learned how multiple Decision Trees are combined through ensemble voting to produce more stable predictions.</li><li><b>Feature Importance</b> – Used Random Forest to identify important factors, with sleep hours and daily social media usage ranking highly in the dataset.</li><li><b>Model Comparison</b> – Compared a single Decision Tree with Random Forest and understood the trade-off between raw accuracy, stability, interpretability, and overfitting.</li></ul>                                   |
| **Day 15** | **20/07/2026** | <ul><li><b>Linear Regression</b> – Learned how to predict continuous numerical values by finding the best-fit relationship between input features and the target.</li><li><b>Ridge Regression</b> – Introduced L2 regularization to reduce the influence of large coefficients and improve model stability.</li><li><b>Lasso Regression</b> – Introduced L1 regularization to shrink some coefficients to zero and perform automatic feature selection.</li><li><b>Regularization</b> – Understood how Ridge and Lasso help control overfitting and reduce the effect of irrelevant or redundant features.</li><li><b>Model Evaluation</b> – Compared Linear, Ridge, and Lasso using Accuracy, R² Score, and Mean Squared Error (MSE).</li><li><b>Feature Selection</b> – Observed that Lasso can remove irrelevant features such as favorite color or sports by setting their coefficients to zero.</li><li><b>Model Comparison</b> – Learned that regularization can improve model simplicity and stability without significantly reducing predictive performance.</li></ul>                                                  |
