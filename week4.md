| **Day 16** | **21/07/2026** | <ul><li><b>Feature Selection</b> – Learned how to identify and retain relevant features while removing irrelevant, redundant, or noisy variables before model training.</li><li><b>Feature Selection Methods</b> – Introduced Filter Methods, Wrapper Methods, and Embedded Methods and understood their different approaches.</li><li><b>Variance Threshold</b> – Removed low-variance or near-constant features that provide little useful information to the model.</li><li><b>Correlation Analysis</b> – Used correlation coefficients and heatmaps to identify linear relationships, feature importance, and potential multicollinearity.</li><li><b>Chi-Squared Test</b> – Learned how to measure the dependency between categorical features and the target variable.</li><li><b>Mutual Information</b> – Used mutual information to identify both linear and non-linear relationships between features and the target.</li><li><b>ANOVA F-Test</b> – Used F-scores and P-values to determine how strongly continuous features differ across target classes.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Day 17** | **22/07/2026** | <ul><li><b>Wrapper Methods</b> – Learned how machine learning models can evaluate different feature subsets and select combinations that provide better predictive performance.</li><li><b>Forward Selection</b> – Started with no features and added features one at a time based on model performance improvement.</li><li><b>Backward Elimination</b> – Started with all features and progressively removed less useful features while maintaining model performance.</li><li><b>Recursive Feature Elimination (RFE)</b> – Repeatedly removed the least important features based on model coefficients or feature importance until the desired number remained.</li><li><b>RFECV</b> – Extended RFE by using cross-validation to automatically determine the optimal number of features.</li><li><b>Model-Based Selection</b> – Used Logistic Regression and Decision Tree models to evaluate feature subsets and identify the most useful variables.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Day 18** | **23/07/2026** | <ul><li><b>Hyperparameter Tuning</b> – Learned how to find optimal model configuration settings before training to improve performance and generalization.</li><li><b>Parameters vs Hyperparameters</b> – Distinguished between parameters learned automatically from data and hyperparameters manually configured before training.</li><li><b>Decision Tree Hyperparameters</b> – Explored settings such as <code>max_depth</code>, <code>min_samples_split</code>, <code>min_samples_leaf</code>, and <code>criterion</code>.</li><li><b>Random Forest, KNN & SVM Hyperparameters</b> – Studied important settings such as <code>n_estimators</code>, <code>n_neighbors</code>, <code>weights</code>, <code>C</code>, <code>kernel</code>, and <code>gamma</code>.</li><li><b>GridSearchCV</b> – Used exhaustive cross-validation to test all specified hyperparameter combinations and identify the best configuration.</li><li><b>RandomizedSearchCV</b> – Used randomized sampling of hyperparameter combinations to search large parameter spaces more efficiently.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Day 19** | **24/07/2026** | <ul><li><b>Machine Learning Pipelines</b> – Learned how to combine preprocessing and model training into a single automated workflow.</li><li><b>Data Leakage Prevention</b> – Understood how pipelines prevent information from the test data leaking into training during cross-validation.</li><li><b>Pipeline & ColumnTransformer</b> – Used <code>Pipeline</code> and <code>ColumnTransformer</code> to handle numerical and categorical features through different preprocessing steps.</li><li><b>End-to-End Workflow</b> – Combined imputation, scaling, encoding, and model training so the complete process runs consistently through <code>.fit()</code> and <code>.predict()</code>.</li><li><b>Model Interpretation</b> – Learned why understanding model decisions is important for trust, debugging, and responsible machine learning.</li><li><b>Global & Local Interpretability</b> – Distinguished between understanding overall feature influence and explaining an individual prediction.</li><li><b>Explainability Tools</b> – Introduced feature coefficients, tree-based feature importance, SHAP, and LIME for interpreting model predictions.</li></ul>                                                                                                                                                                                                                                                                                                            |
| **Day 20** | **27/07/2026** | <ul><li><b>Capstone Project – MediVitals AI Pro</b> – Completed and presented an end-to-end healthcare machine learning project for predicting early health risk indicators from patient data.</li><li><b>Project Architecture</b> – Structured the project into data ingestion, preprocessing, model training, and evaluation components following software engineering practices.</li><li><b>Pipeline Integration</b> – Built a scikit-learn <code>Pipeline</code> with <code>ColumnTransformer</code> for imputation, scaling, and categorical encoding while preventing data leakage.</li><li><b>Model Optimization</b> – Compared Random Forest, Gradient Boosting, and SVM models and optimized them using GridSearchCV and RandomizedSearchCV.</li><li><b>Model Evaluation</b> – Used Precision, Recall, F1-Score, and ROC-AUC to evaluate model performance, with emphasis on minimizing false negatives for critical health alerts.</li><li><b>Model Interpretability</b> – Incorporated feature importance and evaluation reports to improve transparency and understand model behavior.</li><li><b>Model Deployment</b> – Exported the finalized machine learning pipeline using <code>joblib</code> for integration with a web interface or API.</li><li><b>End-to-End ML Development</b> – Integrated skills from data exploration, feature engineering, feature selection, model building, tuning, pipelines, evaluation, and deployment into one complete project.</li></ul> |
